THE ARCHITECTURE EVOLUTION
From execution certification
to compliance verification.

Our research evolved beyond execution certification into something structurally more defensible. The key finding: fraud detection from live market data is proven impossible without cross-broker, account-level access. But the control that would catch it already exists — inside the AMC, mandated by SEBI, confidential to the regulator. ARYA tests that control directly, rather than trying to reconstruct it from the outside.

"The old question was: did the broker execute what I authorized? The new question is sharper and more defensible: did the fund manager's mandated compliance control actually work when tested? That is a question ARYA can answer today, with evidence, not assumption."

The Four-Layer Architecture:

Layer 1 — CASE LIBRARY Real, named, verified SEBI enforcement cases Each modeled as a synthetic injection pattern Expanding with every new confirmed case Layer 2 — REGULATORY INTELLIGENCE (LIVE RAG) SEBI circulars — live vector DB Aug 2024 AMC surveillance mandate Cross-market patterns (MAS Notice 609, others) Layer 3 — TEST AGENT Selects relevant test patterns per AMC Injects synthetic scenarios via defined protocol Captures and structures the AMC's alert response Flags ambiguous results for human review Layer 4 — VERIFICATION REPORT Dated, falsifiable pass/fail per pattern tested Plain-language explanation of what was tested Delivered directly to the commissioning investor Explicit limits stated — a snapshot, not a guarantee

THE VERIFICATION PROTOCOL
Investor-commissioned.
Never AMC-paid.

The commissioning relationship is the most important design decision in ARYA's architecture. Here is the complete protocol:

Step 1 — Commission QIB, family fund house, or HNI selects the AMC to verify ARYA is never commissioned by the AMC itself Step 2 — Select Pattern Arya Test Agent selects relevant test patterns for this AMC Patterns are drawn from the real, named case library Step 3 — Inject Synthetic test data injected into the monitored workflow Never live client trades, never real capital at risk Step 4 — Capture AMC's own SEBI-mandated surveillance system responds — or doesn't ARYA reads and structures the actual output, unaltered Step 5 — Report Dated, falsifiable verification report generated Delivered directly to the commissioning investor
No issuer-pays conflict — commissioned by the investor evaluating the AMC, never the AMC being tested. This avoids the Moody's/EY failure mode by construction, not by policy.
Evidence, not a rating — a pass is a dated snapshot answering whether the control worked when tested. It is never presented as a guarantee it always will.
Compounding case library — every new confirmed SEBI enforcement action becomes a new test pattern, sharpening every future verification.
